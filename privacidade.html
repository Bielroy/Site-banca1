Privacidade

O que a banca guarda sobre você, para que serve e como pedir para apagar.

O que pedimos

Para montar e entregar o seu pedido, o site pede:

  • Nome, condomínio e quadra e lote (ou rua e número): para saber de quem é o pedido e onde entregar.
  • Ofertas no WhatsApp: só enviamos novidades e promoções para quem marca essa opção ao fazer o pedido. Para parar de receber, faça um pedido sem marcar ou peça pelo WhatsApp.
  • WhatsApp (opcional): para avisar quando o pedido estiver pronto.
  • Itens, forma de pagamento, troco e observações do pedido.

O site não pede CPF, e-mail nem senha, e não guarda dados de cartão.

Para que usamos

  • Separar, pesar e entregar o pedido.
  • Mostrar a você o andamento em “Meus Pedidos”.
  • Saber o que mais sai em cada dia para comprar a quantidade certa na Ceasa.
  • Colocar no começo da vitrine os produtos que a sua casa costuma pedir. Isso é calculado pelo endereço de entrega (condomínio, quadra e lote) dos pedidos anteriores.

Não vendemos nem repassamos seus dados para propaganda.

O que fica no seu celular

Para você não digitar tudo de novo, o navegador guarda no próprio aparelho o carrinho, o último endereço usado, seus favoritos e os últimos pedidos. Limpar os dados do site no navegador apaga tudo isso.

Quem mais participa

  • WhatsApp: ao finalizar, o pedido é enviado por mensagem para a banca. Se o pedido tiver itens de mais de um atendimento, cada parte vai para o WhatsApp responsável.
  • Google Firebase: é o banco de dados onde os pedidos ficam guardados. O site cria uma identificação anônima para o seu aparelho, sem cadastro.
  • Vercel: é onde o site fica hospedado.
  • Google Gemini: só se você usar o Ajudante da Banca. A mensagem que você escreve, a foto que enviar e os itens do carrinho são mandados para a inteligência artificial responder. Não escreva dados pessoais na conversa.

Seus direitos

Você pode pedir para ver, corrigir ou apagar os dados dos seus pedidos, como prevê a Lei Geral de Proteção de Dados (LGPD). É só chamar a banca pelo WhatsApp usado para os pedidos.
