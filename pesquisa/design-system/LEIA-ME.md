# Estudo de design system (só leitura)

Esta pasta guarda uma PESQUISA. Nada aqui é carregado pelo site, pelo painel ou pelo servidor.

- `relatorio.html`: o relatório completo (28 repositórios, licenças, tamanhos, proposta e decisões pedidas).
- `prototipo.html`: as telas de protótipo em HTML e CSS (prefixo `ub-`), para abrir no navegador.
- `img/`: as imagens das pranchas usadas no relatório.

Feito em 12/11/2026. Nenhum arquivo do site foi alterado nesta branch e nenhuma dependência foi instalada.
Os ícones das pranchas são do Lucide (licença ISC, https://github.com/lucide-icons/lucide).
As letras são Fraunces e Figtree (licença OFL), as mesmas que o site já usa.
